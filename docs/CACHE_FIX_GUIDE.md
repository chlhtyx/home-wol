# 解决浏览器缓存问题

> 命令均从项目根目录执行；当前目录布局和启动方式见[项目 README](../README.md)。旧目录示意保留作参考。

## 问题原因

浏览器缓存了旧版本的 JavaScript 文件，导致密钥编辑功能无法使用。

## 解决方案

### 方法 1：强制刷新浏览器（推荐）

#### Windows/Linux
- **Chrome/Edge**: `Ctrl + Shift + R` 或 `Ctrl + F5`
- **Firefox**: `Ctrl + Shift + R` 或 `Ctrl + F5`
- **Safari**: `Ctrl + R` 或 `Cmd + Shift + R`

#### Mac
- **Chrome/Edge**: `Cmd + Shift + R`
- **Firefox**: `Cmd + Shift + R`
- **Safari**: `Cmd + Option + R`

### 方法 2：清除浏览器缓存

#### Chrome/Edge
1. 打开开发者工具（F12）
2. 右键点击刷新按钮
3. 选择"清空缓存并硬性重新加载"

#### Firefox
1. 按 `Ctrl + Shift + Delete`
2. 选择"缓存"
3. 点击"立即清除"

#### Safari
1. 按 `Cmd + Option + E`
2. 或者：菜单 → 开发 → 清空缓存

### 方法 3：无痕模式测试

打开无痕/隐私浏览窗口：
- **Chrome/Edge**: `Ctrl + Shift + N`
- **Firefox**: `Ctrl + Shift + P`
- **Safari**: `Cmd + Shift + N`

## 技术细节

### 版本控制

已为静态文件添加版本参数：
- HTML: `<script src="js/app.js?v=2.0">`
- CSS: `<link href="css/style.css?v=2.0">`

### 为什么需要版本号？

浏览器会缓存静态文件以提高加载速度。当文件更新但 URL 不变时，浏览器会使用缓存的旧版本。

通过添加 `?v=2.0` 参数，浏览器认为这是一个新的资源，会重新下载。

### 下次更新

每次更新前端代码后，记得修改版本号：
```html
<script src="js/app.js?v=2.1">  ← 递增版本号
```

## 常见问题

### Q: 为什么清除缓存后还是旧版本？

**A**: 可能需要：
1. 关闭所有标签页
2. 完全关闭浏览器
3. 重新打开浏览器
4. 访问网站

### Q: 无痕模式是正常的，普通模式不是？

**A**: 说明确实是缓存问题：
1. 清除浏览器缓存
2. 或者在普通模式也使用 Ctrl+Shift+R 强制刷新

### Q: 服务端日志显示正常，但前端还是旧版本？

**A**: 100% 是浏览器缓存问题：
1. 尝试无痕模式（如果正常就确认是缓存）
2. 清除浏览器缓存
3. 或者使用不同的浏览器
