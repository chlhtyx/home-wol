## 🆘 需要帮助？

### 问题：强制刷新后还是旧版本
**解决**：
1. 关闭所有标签页
2. 完全关闭浏览器
3. 重新打开浏览器
4. 访问网站
5. 或者使用无痕模式

### 问题：看到新界面但密钥字段不可编辑
**解决**：
1. 检查是否有 `readonly` 属性
2. 查看浏览器控制台（F12）是否有错误
3. 确认加载的是 v2.0 版本

### 问题：保存后密钥没有更新
**解决**：
1. 检查网络请求（F12 → Network）
2. 查看 PUT 请求的 body
3. 确认 secret 字段有值
4. 检查服务器日志
